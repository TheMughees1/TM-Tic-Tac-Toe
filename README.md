# TM Tic Tac Toe

A polished, responsive Tic Tac Toe game built with **HTML, CSS, and vanilla JavaScript**. Play against an AI opponent with three difficulty levels or challenge a friend in local two-player mode.

<p align="center">
  <a href="https://themughees1.github.io/TM-Tic-Tac-Toe/"><strong>▶ Play the Live Demo</strong></a>
</p>

## Features

- **Play vs AI** — challenge a computer opponent.
- **Three AI difficulty levels**
  - **Easy:** makes random moves.
  - **Medium:** looks for winning moves, blocks immediate threats, and prefers the center when available.
  - **Hard:** uses the Minimax algorithm to make optimal decisions.
- **Two-player mode** — play locally with a friend on the same device.
- **Score tracking** — keep track of wins for X and O, plus draws.
- **New Round and Reset Score** — restart a round or clear the scoreboard.
- **Responsive design** — adapts to mobile and desktop screens.
- **Accessible interactions** — clear status updates, labeled board cells, and visible keyboard focus.
- **No installation required** — runs directly in a modern web browser.

## Built With

- **HTML5** for the game structure
- **CSS3** for the dark interface, responsive layout, and visual effects
- **Vanilla JavaScript** for gameplay, score tracking, and AI logic

## Getting Started

### Play Online

Visit the [TM Tic Tac Toe live demo](https://themughees1.github.io/TM-Tic-Tac-Toe/).

### Run Locally

1. Clone or download this repository.
   ```bash
   git clone https://github.com/TheMughees1/TM-Tic-Tac-Toe.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No dependencies, build tools, or package installation are required.

## How to Play

1. Choose **Play vs AI** or **Two players**.
2. If playing against the AI, choose **Easy**, **Medium**, or **Hard**.
3. Select an empty square to place your mark.
4. Get three matching marks in a row, column, or diagonal to win.
5. Use **New Round** to play again or **Reset Score** to clear the scores.
